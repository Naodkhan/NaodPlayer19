# NAOD PLAYER — Android Studio Project

ይህ project የ **NAOD PLAYER** HTML appን ወደ Android WebView app ይጠቀልላል።

## እንዴት APK እንደሚያወጣ
1. Android Studio ክፈት።
2. `Open` በመጫን ይህን project ክፈት።
3. Gradle Sync እስኪጨርስ ጠብቅ።
4. **Build → Build App Bundle(s) / APK(s) → Build APK(s)** ምረጥ።
5. APKውን በ `app/build/outputs/apk/debug/app-debug.apk` ውስጥ ታገኘዋለህ።

### የተካተቱት
- NAOD PLAYER Android mobile UI
- Photo branding / app icon
- Music player
- Video player
- Video fullscreen support
- Local HTML app bundled inside the APK
